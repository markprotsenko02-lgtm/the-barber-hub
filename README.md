# The Barber Hub

Crea una plataforma web especializada para portfolios y contratación de barberos ('BarberMatch' o similar).

La plataforma permite a los barberos mostrar su trabajo y a las barberías descubrir y fichar talento:

1. Directorio público y buscador de barberos:
   - Filtros por: ciudad, especialidad (fade/degradado, arreglo de barba, corte a tijera clásico, coloración, freestyle/diseño), tipo de contrato buscado (jornada completa, media jornada, freelance/autónomo, alquiler de sillón), disponibilidad y rango salarial esperado.
   - Vista en cuadrícula con tarjetas visuales destacando los mejores cortes, especialidad, ciudad y experiencia.

2. Perfil y Portfolio del Barbero:
   - Galería de fotos y vídeos de cortes y peinados realizados (con visor lightbox/modal).
   - Datos profesionales: especialidad, años de experiencia, formación y certificaciones de barbería/academias.
   - Condiciones y preferencias laborales: ciudad, disponibilidad (inmediata, parcial, etc.), tipo de contrato que busca y salario o ingresos esperados.
   - Botón directo de contacto para barberías interesadas (vía WhatsApp, email o formulario de contacto rápido).

3. Panel del Barbero (Creación y edición de portfolio):
   - Formulario para completar y actualizar su perfil, formación, expectativas laborales y subir nuevas fotos/vídeos a su galería de trabajos.

4. Diseño e interfaz:
   - Estilo visual moderno y urbano propio del mundo de la barbería (modo oscuro elegante con acentos cálidos/dorados o metálicos, estética cuidada).
   - 100% adaptado a dispositivos móviles.
   - Con datos de prueba atractivos y realistas de varios barberos con fotos de cortes, formación y preferencias laborales para probar la web desde el primer segundo.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
